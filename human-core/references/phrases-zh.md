# 中文：需要清除的词汇与短语

## 开场白套话

直接说重点，删掉这些铺垫。

- "在当今……的背景下" / "在这个……的时代"
- "随着科技的发展……" / "随着XX的不断发展……"
- "在当今社会……"
- "众所周知" / "不可否认"
- "毫无疑问" / "毫不夸张地说"
- "正如我们所知" / "如前所述"
- "事实上" / "坦白说" / "说实话"（当作空洞开头时）
- "值得注意的是" / "值得一提的是"
- "不难发现"
- "让我们深入探讨" / "接下来让我们" / "让我们来看看"
- "在深入探讨之前，我们需要先了解"

"值得注意的是"和"不难发现"是中文 AI 文本最强的两个识别信号之一。

## 过渡连接词

AI 把这些连接词堆得比真人密集得多。删除或重组句子。

### 顺序标记（最强红旗）

- "首先……其次……再次……最后……"
- "第一……第二……第三……"

一篇文章里四个顺序标记全出现，几乎可以断定是 AI 写的。

### 递进 / 补充

- "此外" / "除此之外"
- "不仅如此"
- "与此同时"
- "再者"
- "尤其是"
- "更重要的是"

### 转折

- "然而"（中文 AI 的 "however"）
- "尽管如此"
- "不可避免地"

### 因果

- "因此" / "由此可见"
- "基于此" / "鉴于"
- "因而"

### 总结

- "综上所述"（最典型的 AI 结尾）
- "总而言之" / "总的来说"
- "回看全貌"
- "基于以上分析"

## 聊天机器人痕迹

- "希望这对您有帮助！"
- "如果您想了解更多……"
- "请告诉我" / "请随时提问"
- "好的，我将为您……"
- "当然！" / "一定！"
- "好问题！" / "您说得完全正确！"
- "截至我最后的训练数据……"
- "根据可用信息……"
- "虽然具体细节有限……"

## 含糊宣言

只说"很重要"却不说具体是什么。删掉或换成具体内容。

- "意义重大" / "影响深远"
- "不可忽视" / "至关重要"
- "将产生深远影响"
- "具有里程碑意义"
- "取得了圆满成功"

## 模糊归因

- "行业报告显示……"
- "专家认为……"
- "有人指出……"
- "研究表明……"

说出专家名字。给出研究机构和年份。

## 公文体套话

这些来自政府公文和官方媒体，AI 训练数据里含量极高，会不自觉地复制。

- "取得了圆满成功"
- "参与者反响热烈"
- "大家纷纷表示受益匪浅"
- "推动XX发展"
- "展现XX潜力"
- "站在历史的转折点"

## AI 高频词汇 — 替换或删除

### 第一档：最强识别信号

一段话里出现两三个就可以断定 AI。

| AI 词汇 | 替换为 |
|---------|--------|
| 至关重要 / 举足轻重 | 重要（或说明为什么重要） |
| 不可或缺 / 无可替代 | 必要的、少不了 |
| 深入探讨 / 深入研究 / 深度剖析 | 看看、说说、分析 |
| 彰显 / 凸显 | 说明、表明 |
| 赋能 / 助力 / 加持 | 帮助、支持 |
| 践行 / 深耕 | 做、专注于 |
| 不断演变的格局 | （说明具体变化） |
| 充满活力的 | （具体描述） |
| 令人叹为观止 | （说具体的感受） |
| 开创性的 | （说明具体开创了什么） |

### 第二档：宏大概念词

这些词抽象、万能、什么话题都能插，正因如此 AI 爱用。

| AI 词汇 | 替换为 |
|---------|--------|
| 格局 | 情况、局面 |
| 维度 | 方面、角度 |
| 赋能 | 帮助 |
| 闭环 | 完整流程 |
| 抓手 | 办法、手段 |
| 落地 | 实施、做出来 |
| 智慧（如"智慧城市"）| 用具体技术名称 |
| 时代（如"在这个AI时代"）| 删掉或说具体年份 |
| 力量（如"XX的力量"）| （具体描述效果） |

### 第三档：空洞强调词

| AI 词汇 | 替换为 |
|---------|--------|
| 显而易见 | （删掉，直接说） |
| 毋庸置疑 | （删掉，直接说） |
| 不言而喻 | （删掉，直接说） |
| 意义重大 | （说明具体意义） |
| 深远影响 | （说明具体影响） |
| 极具潜力 | 可能会…… |
| 无与伦比 | （说明具体好在哪） |

### 第四档：伪技术隐喻

AI（尤其 DeepSeek）用科技术语做文学比喻，违和感极强。

- 量子纠缠（比喻人际关系）
- 解构（伪学术填充）
- 熵增（比喻抽象过程）
- 拓扑（DeepSeek 标志性用词）
- 克莱因瓶（DeepSeek 标志性意象）

除非真的在讨论物理 / 数学，否则删掉。

## AI 滥用的成语

AI 把这些成语当"安全牌"高频插入，真人不会这样堆砌。

- 博大精深 / 源远流长（任何文化话题必出现）
- 与时俱进（官方语言）
- 日新月异（任何科技话题必出现）
- 潜移默化
- 任重道远（AI 最爱的结尾成语）
- 不言而喻
- 举足轻重

成语本身不是问题。问题是 AI 把它们当填充物机械地塞进每段话。一篇短文出现三个以上四字成语，就值得警惕。

## GPT 系列中文口癖

### GPT 的谄媚模板

- "我会稳稳地接住你"（据信来自中文 RLHF 标注者偏好）
- 过度使用"当然可以！""没问题！"

### GPT-5.x 的口头禅

废话类：好 / 行 / 说穿 / 不踩坑 / 简单的说 / 一句话总结 / 结论先说清楚

假装接地气：兜底 / 落盘 / 闭环 / 口径 / 拆开 / 不躲 / 不藏 / 不绕 / 不逃 / 说人话就是

"硬"执念：更硬 / 硬写 / 稳稳接住 / 压实 / 更稳 / 最稳 / 收口 / 收敛 / 收束 / 锁住

过度殷勤：顺手 / 我先 / 你一回复 / 如果你要 / 要不要我 / 我已确认 / 我立马开始

## DeepSeek 中文风格

DeepSeek 有一种"赛博浪漫散文风格"，特征明显：

- 伤口总是"0.01公分"
- 时间总是"持续三分半钟"
- 眼睛是"暗红色的瞳仁"
- 高频意象：拓扑、克莱因瓶、第X根睫毛、青苔、赛博、齿轮、白衬衫
- 比喻如："肩胛骨在晨光中震颤如振翅的拓扑曲面"

用户评价：无病呻吟。看到这类风格直接重写。

## 人味标记 — 真人会用但 AI 不会

修改文本时，适当加入这些标记让文字更有人味：

### 口语化标记
说实话 / 其实 / 怎么说呢 / 坦率地讲 / 别小看 / 太关键了 / 说到底 / 你想想看 / 更别说 / 甚至

### 个人化表达
我认为 / 可能是 / 确实 / 见怪不怪
"不得不说，这一点我起初也没想到"
"说实话，我当时差点放弃了"

### 具体细节（AI 总是含糊）
- 不用"近年来" → 用"2025 年 3 月"
- 不用"某些地区" → 用"杭州余杭区"
- 不用"大幅增长" → 用"增长了 47%"
- 不用"有人说" → 给出人名
