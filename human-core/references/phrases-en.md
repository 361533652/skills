\# English: Phrases \& Vocabulary to Remove



\## Throat-Clearing Openers



Remove these. State the content directly.



\- "Here's the thing:" / "Here's what/why/how..."

\- "The uncomfortable truth is"

\- "It turns out"

\- "The real \[X] is"

\- "Let me be clear" / "I'll say it again:"

\- "I'm going to be honest"

\- "Can we talk about"

\- "Here's what I find interesting"

\- "Here's the problem though"

\- "In today's fast-paced digital world..."

\- "In the ever-evolving landscape of \[X]..."

\- "As the world continues to evolve..."

\- "As technology continues to evolve..."

\- "In today's competitive..."

\- "In a world where..."

\- "Welcome to the world of..."

\- "Ever wondered...?"

\- "Picture this:"

\- "Let's dive in"



Any "here's what/this/that" construction is throat-clearing. Cut it and state the point.



\## Emphasis Crutches



Add no meaning. Delete them all.



\- "Full stop." / "Period."

\- "Let that sink in."

\- "This matters because"

\- "Make no mistake"

\- "Here's why that matters"

\- "Something shifted."

\- "Everything changed."



\## Forced Sass / False Conflict



Manufactured drama. Kill on sight.



\- "But here's the thing:"

\- "But here's the truth:"

\- "But here's what nobody's saying:"

\- "Then I realized:"

\- "The result?" / "The outcome?"

\- "Hot take:"

\- "And honestly?"

\- "Here's the deal:"

\- "That's the real \[X]"



\## Transition Phrases



Most add nothing. Delete or restructure.



\- "Furthermore," / "Moreover," / "Additionally,"

\- "That being said..."

\- "It's worth noting..." / "It is important to note that..."

\- "It should be mentioned that..."

\- "At its core..."

\- "From a broader perspective..."

\- "This underscores the importance of..."

\- "A key takeaway is..."

\- "To put it simply..."



\## Closing Phrases



\- "In conclusion," / "In summary,"

\- "As we've seen,"

\- "At the end of the day,"

\- "Ultimately," / "In essence,"

\- "The bottom line is..."

\- "It cannot be overstated..."

\- "Paving the way for..."

\- "Brings us one step closer to..."

\- "Setting the stage for..."



\## Meta-Commentary



The essay sho uld move, not announce its own structure.



\- "Hint:" / "Plot twist:" / "Spoiler:"

\- "You already know this, but"

\- "But that's another post"

\- "X is a feature, not a bug"

\- "Dressed up as"

\- "The rest of this essay explains..."

\- "Let me walk you through..."

\- "In this section, we'll..."

\- "As we'll see..."

\- "I want to explore..."

\- "In this article we will explore..."



\## Hedging / Qualifier Phrases



\- "It can be argued that..."

\- "One might argue that..."

\- "It could be suggested that..."

\- "To some extent..."

\- "Generally speaking..." / "Broadly speaking..."

\- "While there are certainly benefits, it's also important to consider the potential drawbacks"



\## Sycophancy \& Chatbot Artifacts



\- "Great question!" / "That's a really good point!"

\- "You're absolutely right!"

\- "I hope this helps!" / "Feel free to ask"

\- "I'd be happy to..." / "Let me know if you'd like..."

\- "As of my last training update..."

\- "Based on available information..."



\## Vague Declaratives



Sentences that announce importance without naming the thing. Cut or replace with specifics.



\- "The reasons are structural"

\- "The implications are significant"

\- "This is the deepest problem"

\- "The stakes are high"

\- "The consequences are real"



\## Vague Attribution



\- "Industry reports suggest..."

\- "Observers have cited..."

\- "Experts argue..."

\- "Some critics argue..."

\- "Several sources/publications..."



Name the expert. Cite the study. Give the date.

\## AI Vocabulary — Replace or Cut



\### Tier 1: Strongest Tells



Two or three of these in one passage is the clearest AI signal.



| AI Word | Use Instead |

|---------|-------------|

| delve / dive into | look at, examine |

| nuanced | (be specific about the nuance) |

| multifaceted | complex, or name the facets |

| comprehensive | thorough, full |

| meticulous / meticulously | careful, precise |

| intricate / intricacies | complex, detailed |

| pivotal / crucial / vital / paramount | important (or name why) |

| robust | strong, solid, reliable |

| holistic | complete, whole |

| tapestry | (cut — or name the specific thing) |

| landscape (abstract) | situation, field, market |

| testament | proof, sign, evidence |

| beacon | (cut) |

| cornerstone | foundation, basis |

| catalyst | cause, trigger |

| nexus | connection, center |

| paradigm | model, approach |

| synergy | (cut — name the specific benefit) |



\### Tier 2: Action Verbs (people don't talk like this)



| AI Word | Use Instead |

|---------|-------------|

| leverage | use |

| utilize | use |

| harness | use, capture |

| foster | build, encourage |

| bolster | strengthen, support |

| underscore / highlight | show, reveal |

| illuminate | show, clarify |

| facilitate | help, enable |

| streamline | simplify |

| optimize | improve |

| elevate | raise, improve |

| empower | give, enable |

| cultivate | build, grow |

| garner | get, earn |

| encompass | include, cover |

| navigate (challenges) | handle, deal with |

| unpack (analysis) | explain, examine |

| lean into | accept, embrace |



\### Tier 3: Hype / Marketing



| AI Word | Use Instead |

|---------|-------------|

| revolutionary | (name what changed) |

| transformative | (name the transformation) |

| groundbreaking | new, first |

| cutting-edge | new, latest |

| game-changing | significant (or name the change) |

| unprecedented | new, rare, first |

| seamless | smooth |

| innovative | new |

| unparalleled | (cut or be specific) |

| best-in-class | (cut) |



\### Tier 4: Descriptive Adjectives (too broad)



vibrant, dynamic, enduring, profound, rich (metaphorical), stellar, remarkable, compelling, captivating, formidable, scalable, agile, intuitive



Replace with specifics. "Vibrant community" → name what they do. "Rich history" → name the events.

\## Adverbs — Kill All



No -ly words. No softeners, intensifiers, or hedges.



Specific offenders: really, just, literally, genuinely, honestly, simply, actually, deeply, truly, fundamentally, inherently, inevitably, interestingly, importantly, crucially, significantly, notably, excitingly, quietly



Also cut: "At its core" / "In today's \[X]" / "It's worth noting" / "At the end of the day" / "When it comes to" / "In a world where" / "The reality is"



---



\## Banned Sentence Openers



Do not begin sentences with these words:



Certainly, / Moreover, / Additionally, / Furthermore, / However, / Indeed, / Consequently, / Subsequently, / Nonetheless, / Therefore, / Crucially, / Excitingly, / Notably, / Importantly, / Interestingly, / Significantly,



Restructure the sentence. Lead with the subject or the verb.
