# English: Structures & Patterns to Avoid

## Binary Contrasts

These create false drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliche |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." | Mechanical contrast |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "It's not about X, it's about Y" | LinkedIn cliche |
| "It's not just X. It's Y" | Same formula, shorter |
| "That's not X, that's Y" | Same formula, confrontational |

**Fix:** State Y directly. "The problem is Y." Drop the negation entirely.

## Negative Listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same, past tense |

**Fix:** State Z. The reader doesn't need the runway.

## Dramatic Fragmentation

Sentence fragments for emphasis. Manufactured profundity.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Fix:** Complete sentences. Trust content over presentation.

## Staccato Trio

| Pattern | Problem |
|---------|---------|
| "No [X]. No [Y]. Just [Z]." | Template drama |
| "Focused. Aligned. Measurable." | Corporate incantation |
| "Think bigger. Act bolder. Move faster." | Motivational spam |

**Fix:** Write a sentence.

## Rhetorical Setups

Announce insight rather than deliver i t.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |

**Fix:** Make the point. Let readers draw conclusions.

## The Rhetorical Question Pivot

| Pattern | Problem |
|---------|---------|
| "And the [X]? [Y]." | Template suspense |
| "The result? Higher engagement." | Fake curiosity |
| "The solution? It's simpler than you think." | Clickbait structure |

**Fix:** State the result directly.

## False Agency

Giving inanimate things human verbs. AI does this to avoid naming the actor.

| Pattern | Fix |
|---------|-----|
| "a complaint becomes a fix" | "The engineer fixed it" |
| "a bet lives or dies in days" | "Someone kills the project or ships it" |
| "the decision emerges" | "The team decides" |
| "the culture shifts" | "People change behavior" |
| "the conversation moves toward" | "Someone steers the conversation" |
| "the data tells us" | "We found in the data" |
| "the market rewards" | "Buyers pay for" |

**Fix:** Name the human. If no specific person, use "you."

## Narrator-from-a-Distance

Floating above the scene instead of putting the reader in it.

| Pattern | Fix |
|---------|-----|
| "Nobody designed this." | "You don't sit down one day and decide to..." |
| "This happens because..." | Put the reader in the situation |
| "People tend to..." | "You probably..." |

## Passive Voice

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

Find the actor. Put them first.

## Copulatives Avoidance

AI replaces simple "is"/"are" with elaborate constructions. This is measurable: over 10% decrease in "is"/"are" usage in post-2023 AI text.

| AI Version | Human Version |
|------------|---------------|
| "serves as" / "stands as" | "is" |
| "boasts" / "features" / "maintains" | "has" |
| "represents a shift" | "is a change" |

**Fix:** Use "is" and "has" when they work.

## Sentence Starters to Avoid

| Pattern | Fix |
|---------|-----|
| Sentences starting with What, When, Where, Which, Who, Why, How | Lead with the subject or verb |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

## Formulaic "Challenges" Sections

Near the end of articles: "Despite its [positive words], [subject] faces several challenges..." followed by vague optimism. Often paired with a "Future Prospects" section.

**Fix:** Name the specific challenge and the specific response. Or cut the section.

## Hedging Seesaw

Compulsive balance. "While there are certainly benefits, it's also important to consider..." AI almost never commits to a strong, unbalanced opinion.

**Fix:** Take a position. State it. If both sides genuinely matter, give them unequal weight based on evidence.

## Rhythm Patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists | Use two or four |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends punchily | Vary endings |
| Em dashes | Remove. Use commas or periods |
| Staccato fragments stacked | Don't stack short punchy sentences |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Elegant Variation (Synonym Cycling)

AI aggressively substitutes synonyms due to repetition-penalty code. The protagonist → the main character → the central figure → the hero. All in four sentences.

**Fix:** Repeat the same word when it's the clearest choice. Repetition is fine.

## Formatting Patterns

| Pattern | Problem |
|---------|---------|
| Bold-heading bullet lists (**Key:** text) | Convert to prose |
| Emoji bullet points (🚀💡✅) | Remove emoji |
| Title Case In Every Heading | Use sentence case |
| Excessive bullet points | Write paragraphs |
| Markdown leaking into output | Clean up |
| Thematic breaks before every heading | Remove |

## Present-Participle Analytical Appendages

AI appends shallow analysis via "-ing" phrases at sentence ends:

- "...highlighting the importance of..."
- "...underscoring the need for..."
- "...emphasizing the role of..."
- "...reflecting broader trends in..."
- "...contributing to the..."
- "...ensuring that..."
- "...fostering a..."

**Fix:** If the analysis matters, give it its own sentence with a human subject. If it doesn't, cut it.
