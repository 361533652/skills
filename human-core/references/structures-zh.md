# 中文：需要避免的结构与模式

## "不是……而是……"式（否定+肯定）

中文 AI 最高频的句式之一。用否定来制造转折，然后抛出"真正的"观点。

| 模式 | 问题 |
|------|------|
| "不是A，而是B" | 机械转折，AI 使用频率远高于真人 |
| "不仅A，而且B" | 递进套路，AI 文本中出现频率异常高 |
| "不仅A，而且B，更重要的是C" | 三层递进，公式化到极点 |
| "它不是A，而是B；不是C，而是D" | 双重否定，模板感爆棚 |
| "这不仅仅是A，更是B" | 用来人为拔高意义 |
| "这不仅是A的问题，更是B的问题" | 同上 |
| "与其说是A，不如说是B" | 同样的二元翻转，换了个壳 |

**怎么改：** 直接说B。"问题在于B。"把否定部分整个删掉。

## "从……到……"式（虚假范围）

用来制造"全面"的假象。

| 模式 | 问题 |
|------|------|
| "从X到Y，从A到B" | 假装覆盖面广 |
| "从X到Y，无不体现了……" | 虚假范围 + 空洞总结 |
| "无论是X，还是Y，都……" | 万能涵盖式 |

**怎么改：** 选最重要的一个说清楚。不需要假装面面俱到。

## "随着……"式开头

最容易被识别的 AI 开头之一。

| 模式 | 问题 |
|------|------|
| "随着科技的发展……" | AI 八股开头第一名 |
| "随着XX的不断深入……" | 同上 |
| "在当今社会……" | 空洞的大背景 |
| "在这个XX的时代……" | 假装有时代感 |
| "在……的大背景下……" | 公文体开头 |

**怎么改：** 从具体事件或数据开头。"2025 年 3 月，OpenAI 发布了……"比"随着人工智能技术的不断发展"好一百倍。

## 总分总结构（总-分-总）

几乎所有中文 AI 文章都遵循这个模板：

1. 开头：交代背景 / 说明重要性
2. 中间：三个并列论点，每个有主题句 + 支撑
3. 结尾：综上所述 + 重述观点

**怎么改：** 
- 不要用"综上所述"收尾
- 不要恰好三个论点
- 论点之间可以有轻重之分，不需要平行对称
- 可以用一个具体案例收尾，而不是抽象总结

## 三段式 / 三重式

AI 把所有东西都凑成三组。

| 模式 | 问题 |
|------|------|
| 三个并列形容词 | 机械堆砌 |
| 三个分论点 | 公式化 |
| 三个例子 | 凑数感 |
| "A、B和C" | 永远是三项 |

**怎么改：** 用两项或四项。如果只有两个重要的，就只说两个。

## 排比句堆砌

AI（尤其在中文里）特别喜欢排比：

- "XX是A，XX是B，XX更是C"
- "我们要做到A，做到B，做到C"
- 对偶句：AI 使用对偶句的频率约为真人的 6 倍

**怎么改：** 排比偶尔用一次有效果。连续用就变成了机器。打碎它，用不对称的句子替代。

## 一方面……另一方面

| 模式 | 问题 |
|------|------|
| "一方面……另一方面……" | 机械二元，假装全面 |
| "既要……又要……" | 同上 |

**怎么改：** 如果两面确实都重要，给一面更多篇幅。不要平均分配。

## "挑战与展望"套路

文章快结尾时："尽管面临XX挑战……但前景依然光明"。

| 模式 | 问题 |
|------|------|
| "尽管面临挑战……但……" | 公式化转折 |
| "挑战与机遇并存" | 空洞的辩证法 |
| "任重道远" | AI 最爱的结尾词 |
| "未来展望" 段落 | 模板化章节 |

**怎么改：** 说具体挑战是什么，谁在做什么应对。或者直接把这个段落删了。

## 积极结尾强迫症

AI 几乎总是以积极正面的语气收尾，即使讨论的是负面话题。读起来像"乖巧听话的小学生"。

**怎么改：** 
- 可以用一个开放性问题收尾
- 可以用一个具体的下一步行动收尾
- 可以承认不确定性
- 不需要每篇文章都阳光灿烂

## 段落级重复

每段内部结构完全相同：主题句 → 支撑细节 → 小总结。真人的段落结构变化很大。

**怎么改：** 有的段落只有一句话。有的段落以问题开头。有的段落没有结论。

## 均匀句长

AI 产出的句子长度惊人地一致。真人写作的句子长短交错。AI 的文字读起来像"节拍器"——均匀、可预测、单调。

**怎么改：** 
- 短句接长句。
- 偶尔来一个只有三四个字的句子。
- 别让三个连续句子一样长。

## 过度使用破折号

AI（尤其 ChatGPT）比真人更频繁地使用破折号（——），模仿"有力"的文案风格。

**怎么改：** 用逗号或句号。实在需要补充说明的时候用括号。

## 粗体滥用

AI 机械地用粗体强调短语。

**改写前：**
> 它融合了 **OKR（目标和关键结果）**、**KPI（关键绩效指标）** 和 **商业模式画布（BMC）**。

**改写后：**
> 它融合了 OKR、KPI 和商业模式画布。

## 内联标题列表

AI 输出带粗体标题的列表：

**改写前：**
> - **用户体验：** 用户体验通过新界面得到改善。
> - **性能：** 性能通过优化算法得到增强。
> - **安全性：** 安全性通过端到端加密得到加强。

**改写后：**
> 更新改进了界面，通过优化算法加快了加载时间，并添加了端到端加密。

## 表情符号装饰

AI 用表情符号装饰标题或列表项。

**改写前：**
> 🚀 **启动阶段：** 产品在第三季度发布
> 💡 **关键洞察：** 用户更喜欢简单

**改写后：**
> 产品在第三季度发布。用户研究显示更喜欢简单。

## 同义词循环

AI 因为重复惩罚机制，会强行换同义词：主人公 → 主要角色 → 中心人物 → 英雄。四句话里用了四个词指同一个人。

**怎么改：** 同一个东西就用同一个词。重复比乱换清楚。

## 系动词回避

AI 用复杂结构替代简单的"是""有"。

| AI 写法 | 人话 |
|---------|------|
| "作为XX的代表" | "是" |
| "充当……的角色" | "是" |
| "拥有/设有/提供" | "有" |

**怎么改：** "是"和"有"能用就用。不用刻意绕开。

## 翻译腔

ChatGPT 的中文训练数据只占约 5%，文本经常读起来像英文翻译。句子结构跟随英语语法而非自然中文语序。

特征：
- 主语过多（中文经常省略主语）
- 被动语态过多
- 长定语从句
- "的"字堆砌

**怎么改：** 按照中文习惯重组。主语能省就省。短句优先。
