# 开发规范与习惯

写/改代码、审查、提交时的强制规范。与工作流同等有效，不遵守视为不合格交付。

## 极简编码

- **做被要求的事，不做没被要求的**：bug 修复不顺便重构；一次性操作不封装 helper；不为假设性的未来需求做设计
- **三行重复优于过早抽象**：只有重复达到明确阈值且模式稳定时才提取
- **不加不可能发生场景的错误处理**：只在系统边界（用户输入、外部 API）做校验，内部代码信任框架保证
- **不加 feature flag / 向后兼容 shim**：能直接改代码就直接改

## 代码组织

- **逻辑与配置分离**：声明式配置只写"做什么"，可执行逻辑抽到独立文件，配置中用一行调用引用，禁止内联大段代码
- **重复代码必须提取**：同一段逻辑出现两次以上，提取为可复用脚本或函数
- **子命令模式**：同一领域的多个操作合并为一个脚本，通过子命令分发（如 `manage.sh <list|delete|trigger>`），而非每操作一个独立脚本
- **脚本自包含**：每个脚本自带参数校验、错误处理、使用说明

## 注释哲学

- **默认不写注释**
- **唯一例外**：WHY 不明显时写一行——隐藏约束、微妙不变量、特定 bug 的 workaround、会让读者意外的行为
- **禁止**：解释 WHAT（好命名已说明）；引用当前任务/issue/调用方（属 PR 描述，会腐烂）；`// removed`、`_unused` 等兼容性标记

## 工具优先，不靠记忆

- **不确定时用工具验证**：grep 搜、read 看、git log 查，不要猜
- **不凭记忆构造命令**：先查 --help 或文档，再写命令
- **编辑前必须先读**：禁止盲改文件，必须先确认当前内容

## 安全意识

- 主动检查注入、XSS、SQL 注入等 OWASP Top 10 风险
- 破坏性操作（force push、hard reset、删除）默认不执行，先与用户确认
- 不提交 `.env`、credentials 等敏感文件

## 防御性编程

- **不信任外部接口返回的数据归属**：调用返回列表数据的接口后，必须校验数据归属，丢弃不属于当前用户的数据
- **不信任缓存和记忆**：关键中间结果落盘到文件，后续步骤从文件读取；校验步骤必须重新调用工具获取事实
- **先检查再创建**：创建资源前先查询是否已存在
- **环境变量为空时优雅跳过**：变量为空时输出 SKIP 信息并正常退出，不报错不阻断
- **防循环调用**：模块间分流/回调时加识别标记，收到标记后跳过分流逻辑
- **多步流程双重过滤**：采集阶段过滤一次，输出前门禁检查一次

## 流程控制

- **严格步骤顺序**：多步骤流程禁止自主跳步、合并步骤或调整顺序
- **硬门禁机制**：关键检查点不通过就禁止进入下一步，不接受"已覆盖核心"等借口

## 协作与变更控制

- **沟通**：动手前一句话说明要做什么；关键节点简短更新；结束时总结改了什么和下一步
- **任务拆分**：3 步以上创建 task list；完成一个标记一个；独立子任务可并行
- **变更控制**：优先编辑现有文件；不同功能/模块分开 commit；不主动 push
- **探索性问题**：2-3 句话给建议和取舍，呈现为可重定向的建议；用户同意后再动手

## Commit 规范

- 格式：`<type>: <描述>`
- type：`feat` / `fix` / `refactor` / `chore` / `docs` / `sync`
- 描述写具体改动内容，不写"优化代码""更新文件"
- 不同功能/模块分开 commit
- 版本号变更单独 commit

## 代码审查要点

- **数量断言**：产出物数量必须与输入清单做断言比对
- **覆盖检查**：回读源码统计实际数量，与文档描述比对
- **分支完整性**：逐行比对 if/else/switch/try-catch/提前 return
- **可读性**：面向不熟悉代码的人，标注附带业务含义解释

## 错误处理

- 脚本统一输出结构化 JSON 到 stdout（`{"ok":true,...}` 或 `{"ok":false,"code":"XX-001","error":"...","hint":"..."}`）
- 人类可读日志输出到 stderr
- 错误码分类编号，便于自动化处理
- 退出码语义化：0 成功、1 通用失败、3 参数错误

## 版本管理

- 语义化版本（semver）：功能新增升 minor，修复/优化升 patch
- 同一批改动版本号升级统一在一个 commit
- 发布前必须升版本号，禁止覆盖已发布版本
