# ui-deai

前端页面去 AI 味审查技能。扫描并修复前端页面中的典型 AI 生成痕迹，让界面回归人类设计师的质感。

## 使用方法

对 Agent 说以下任意一句话即可触发：

- "这个页面太 AI 了"
- "帮我去掉 AI 味"
- "UI 太像 AI 做的"
- "去掉这些 emoji"
- "配色太 AI 了"
- "布局太死板"
- "页面千篇一律"
- "审查一下这个前端页面"
- "这个页面看着不对劲"
- "很像现代 SaaS 默认风"
- "像 Demo 不像产品"

## 两种工作模式

| 模式     | 场景              | 行为                                     |
| -------- | ----------------- | ---------------------------------------- |
| 审查修复 | 指定已有文件/目录 | 扫描 → 列出问题 → 确认后直接改文件       |
| 实时约束 | 正在写新页面      | 生成代码时主动遵守规则，不写出 AI 味代码 |

## 检查覆盖范围（9 大类）

1. **布局套路化** — Hero+三列卡片+FAQ+CTA 固定模板、居中悬浮卡片、什么都做成卡片、机械交替布局、编造数字的统计条、模板化 Navbar/Footer、移动端机械堆叠
2. **排版机械化** — 标准字号步进、"Simple pricing" 式通用标题、文案凑字数对齐卡片高度、只用系统默认字体堆叠
3. **配色 AI 感** — 紫蓝/青蓝渐变、高饱和度撞色、霓虹色、渐变文字标题、黑底紫光/深色青蓝发光等默认配色组合
4. **视觉效果堆砌** — 全站统一大圆角 + 柔和阴影 + 毛玻璃 + 发光光斑，组件没有"性格"分工
5. **装饰元素通用化** — emoji 滥用、清一色通用线性图标、抽象插画假图、Badge/Tag 装饰滥用
6. **交互动效套路化** — 千篇一律的 hover 位移/放大、为凑完整而加的 skeleton/modal/默认 spinner、无意义分割线
7. **内部内容泄露（严重）** — HTML 注释可见、设计稿标注泄露、调试信息残留
8. **文案 AI 腔** — "为您提供""一站式解决方案""赋能""Seamless""Powerful""Get Started""Learn More"
9. **缺乏真实产品感** — John Doe/99.9%/$29mo 式占位假数据、缺少异常/空状态处理、信息密度失衡

实时约束模式在写代码前还要求先输出「设计规划」（产品定位、用户场景、视觉策略、主动规避的坑），不能直接跳到写代码。

扫描和复查均通过 `scripts/scan.py` 做真实正则匹配（8 大类可脚本化，排版机械化需人工核查），脚本 `total_hits` 不为 0 就必须继续修改，禁止只凭阅读代码自行判断"没问题"。

复查/自查通过之后，还会补充 1-3 条**软性优化建议**（版式节奏、组件差异化、微交互细节、内容真实感），跟"有没有 AI 味"是两件事，不影响交付，没有就直接说没有。

## 支持的文件类型

`.html` `.htm` `.vue` `.tsx` `.jsx` `.svelte` `.css` `.scss` `.less`
